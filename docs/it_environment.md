# IT environment notes

The bot adds this file to every AI prompt so its troubleshooting matches your tools.
The list below is a sample lab setup. Replace it with what your lab actually runs.

- Identity and sign-in: Microsoft Entra ID with single sign-on, MFA through Microsoft Authenticator
- Email and calendar: Microsoft 365 (Outlook)
- Laptops: Windows 11 managed with Intune, plus a few Macs
- VPN: WireGuard client
- Password manager: Bitwarden
- Chat and meetings: Slack, Zoom
- Ticketing: Jira (tickets are created automatically from Slack posts)

Policies:

- Only the IT team can grant admin rights, software licences or access to systems.
- Lost or stolen devices and suspected phishing should be escalated straight away.
